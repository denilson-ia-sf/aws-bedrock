TITLE: Corporate Office Printer Installation Guide
REVISION: 2026.1
SCOPE: Sao Paulo & New York Corporate Offices

INSTRUCTIONS FOR WINDOWS:
1. Open Windows Settings by pressing Win + I.
2. Navigate to "Bluetooth & devices" > "Printers & scanners".
3. Click on "Add device" and select "The printer that I want isn't listed" if it does not appear automatically.
4. Select "Add a printer using an IP address or hostname".
5. Input Device Type: TCP/IP Device.
6. Input Hostname/IP: 192.168.10.250 (Default Office Printer).
7. Port Name will autofill. Click Next, select "Generic Network Card" if prompted, and finish the wizard.

INSTRUCTIONS FOR MACOS:
1. Open System Settings > Printers & Scanners.
2. Click "Add Printer, Scanner, or Fax..." (the IP tab / globe icon).
3. Type the IP Address: 192.168.10.250.
4. Protocol: AirPrint or Line Printer Daemon (LPD).
5. Click Add.

TROUBLESHOOTING:
If the printer shows as 'Offline', restart the print spooler service or ensure you are connected to the Corporate VPN (if working remotely).
